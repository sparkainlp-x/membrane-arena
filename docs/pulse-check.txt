8. Notes
   A flaw in the frozen protocol, found when it was run: the noise-free reference uses a threshold of k times
   the noise sigma, but smoothing divides the noise SD by sqrt 3, so its threshold is sqrt 3 times higher than
   the noisy detector's. In loud settings it then misses sensors, and it is not a fair reference there. It is
   reported as frozen. An exploratory variant with k sigma / sqrt 3, added after the protocol, gives in the
   default setting 0.55 [0.52, 0.59] and in win/8/loud/even 1.30 [1.08, 1.55] cells.
   The region is the locator's own: a pulse whose locator falls back to the centre (fewer than 3 arrivals) counts as not covered.
   Errors are distances in grid cells. Results apply to this simulation only.
